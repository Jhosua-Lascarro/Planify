# Planify

Planify is a web interface for exploring accommodations and managing a travel booking. The project uses Vite, TypeScript, HTML pages, and shared CSS styles.

## Requirements

- Node.js 20 or later
- npm

## Installation

```bash
npm install
```

## Commands

```bash
npm run dev       # Start the development server
npm run build     # Check TypeScript and create a production build
npm run lint      # Run the linter
npm run fmt:check # Check formatting
```

## Project Structure

```text
Planify/
├── public/                # Public Vite files
├── src/
│   ├── pages/             # HTML pages
│   │   ├── booking.html
│   │   ├── destination.html
│   │   └── explore.html
│   ├── styles/            # Shared styles
│   └── index.html         # Main page
├── package.json
├── tsconfig.json
└── vite.config.ts
```
